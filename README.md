# 🛒 Grocery Store Management Web App

A full-stack grocery store management application built with Python, Flask, and MySQL.

![Homepage](homepage.JPG)

---

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** Python, Flask
- **Database:** MySQL

---

## Features

- View all products in a clean, organized grid
- Add new products with name, unit of measure (UOM), and price
- Delete products
- Pre-loaded UOM options (e.g., kg, litre, dozen)

---

## Installation

**1. Install MySQL**  
👉 https://dev.mysql.com/downloads/installer/

**2. Install Python dependencies**
```bash
pip install flask mysql-connector-python
```

**3. Configure your MySQL credentials in the backend, then run:**
```bash
python server.py
```

**4. Open `index.html` in your browser.**
